Plague Inc

Терминальная многопользовательская стратегическая игра, вдохновлённая Plague Inc. Два игрока подключаются к локальному TCP-серверу, выбирают противоположные стороны и борются за судьбу мира: патоген пытается распространиться и сломить человечество, а человечество пытается сдержать вспышку и завершить разработку лекарства.

Проект написан на C++20. Клиентский интерфейс работает через ncurses.

Возможности

  • Игра на двух игроков по схеме клиент/сервер через TCP.
  • Браузер комнат с публичными и приватными комнатами.
  • Выбор стороны: человечество или патоген.
  • Симуляция мира в реальном времени на основе серверных тиков.
  • Карта мира в терминале.
  • Статистика населения по странам: восприимчивые, заражённые в инкубации, больные, выздоровевшие, умершие.
  • Прогресс лекарства, очки ДНК/улучшений, новостная лента и подсветка событий.
  • Деревья улучшений для путей передачи, клиники/давления на лекарство и способностей.
  • Адаптивные терминальные раскладки для низкого, среднего и высокого разрешения.
  • Логи клиента и сервера.

Геймплей

Матч строится вокруг противостояния двух сторон: вирус(Pathogen) и человечество(Humanity). Игрок за Pathogen пытается превратить локальную вспышку в глобальную пандемию: выбирает первую страну заражения, следит за распространением по миру(World), собирает очки с подсвеченных стран и покупает Upgrade, усиливающие заразность, летальность, устойчивость к лекарству или давление на медицинскую систему. Игрок за Humanity играет от сдерживания: наблюдает за статистикой стран, ускоряет лекарство, повышает информированность населения и покупает Upgrade для карантина, исследований, ограничений транспорта и медицинской инфраструктуры.

World — это серверная модель мира: набор стран, связей между ними, параметров населения, климата, медицины и транспорта. Каждый серверный тик продвигает симуляцию на один игровой день: заражённые переходят между стадиями, болезнь распространяется внутри стран и через транспортные связи, Humanity накапливает прогресс лекарства, а события попадают в новостную ленту. На клиенте World отображается как терминальная карта и панели статистики: заражённые, умершие, выздоровевшие, прогресс cure и текущие points.

Rooms нужны как слой матчмейкинга перед самой партией. Через Rooms игроки создают публичную или приватную комнату, подключаются ко второму игроку, получают закреплённые противоположные роли, выбирают подтип и нажимают Ready. Комната хранит состав игроков, состояние лобби, пароль приватной игры, собственный World, поток игрового цикла и временные события вроде подсвеченной страны с DNA-наградой. Благодаря этому несколько пар игроков могут независимо проходить разные матчи на одном Server, не смешивая состояния.

Основной цикл партии выглядит так:

  1. Игроки подключаются к Server из Client и через Rooms создают или выбирают комнату.
  2. В лобби один игрок становится Pathogen, другой — Humanity; при необходимости стороны можно поменять запросом смены стороны.
  3. После Ready у обоих игроков Server создаёт World и рассылает стартовый снимок состояния.
  4. Pathogen первым кликом выбирает страну стартового заражения.
  5. Далее Server каждые несколько секунд обновляет World, отправляет Client свежую статистику стран, новости, прогресс лекарства и подсветки событий.
  6. Игроки кликают по странам, собирают points/DNA-награды и покупают Upgrade из доступного дерева с учётом стоимости и зависимостей.
  7. Pathogen побеждает за счёт быстрого распространения и роста ущерба, Humanity — за счёт сдерживания вспышки и доведения лекарства до готовности.

Требования

  • Linux или другая POSIX-подобная среда.
  • Компилятор C++20, проверено с g++.
  • make.
  • Пакет разработки ncurses:
    • Debian/Ubuntu: sudo apt install libncurses-dev pkg-config
    • Fedora: sudo dnf install ncurses-devel pkgconf-pkg-config
    • Arch: sudo pacman -S ncurses pkgconf

Используйте настоящий терминал с поддержкой ncurses. Если терминал сообщает TERM=dumb, задайте подходящий тип терминала, например:

export TERM=xterm-256color

Сборка

make

После сборки появятся:

  • build/server
  • build/client

Чтобы удалить артефакты сборки:

make clean

Запуск

Запустите сервер:

./build/server

Запустите клиент:

./build/client

Сервер слушает 0.0.0.0:5555. На экране подключения в клиенте можно ввести адрес и порт.

Как играть

  1. Запустите сервер.
  2. Запустите два клиента.
  3. В каждом клиенте выберите Connect to server.
  4. Создайте комнату или подключитесь к существующей.
  5. Выберите сторону/подтип и нажмите Ready.
  6. Когда оба игрока готовы, игра начнётся.

Патоген побеждает, если распространяется по странам быстрее, чем человечество успевает разработать лекарство. Человечество побеждает, если замедляет распространение, управляет ситуацией в странах и завершает лекарство.

Управление

Интерфейс управляется с клавиатуры:

  • Стрелки: перемещение между пунктами, странами или кнопками.
  • Tab / Shift+Tab: переключение между группами фокуса.
  • Enter: активировать выбранную кнопку или выбрать страну.
  • Esc: вернуть фокус к кнопкам действий на игровом экране.

Горячие клавиши игрового экрана:

  • u: улучшения
  • i: экран патогена/информации
  • t: улучшения передачи
  • c: улучшения клиники
  • a: улучшения способностей
  • w: экран стран/мира
  • r: экран лекарства
  • n: экран новостей

Структура проекта

Модуль Файлы Роль в системе Что делает
Client Client/Inc/*.hpp, Client/Src/*.cpp Клиентское приложение и сетевой слой игрока Запускает игровой цикл клиента, подключается к Server через SocketTransport, отправляет команды (Connect, ListRooms, CreateRoom, JoinRoom, Ready, SelectCountry, PurchaseUpgrade), парсит ответы сервера и обновляет локальный GameState для интерфейса.
Server Server/Inc/*.hpp, Server/Src/*.cpp Авторитетная игровая логика, комнаты и TCP-сервер Принимает подключения, обрабатывает команды клиентов, управляет Rooms через LobbyManager, создаёт и запускает матч, хранит общий World комнаты, начисляет points, проверяет покупку Upgrade, двигает симуляцию и рассылает тики обоим игрокам.
Common Common/Inc/*.hpp, Common/Src/*.cpp Общий контракт между Client, Server и Interface Описывает роли Pathogen/Humanity, GameSituation, протокол Client_ServerAPI, структуры World/страны/населения/вакцины, определения Upgrade, общие utilities и logger.
Interface Interface/Inc/*.hpp, Interface/Src/*.cpp, Interface/Inc/Maps/* Терминальный ncurses-интерфейс Рисует Main Menu, Connect, Room Browser, Choosing Side, Game, Upgrade, World/Country, Cure, News и End Screen; обрабатывает навигацию, карту стран, виджеты, адаптивные раскладки и превращает действия пользователя в UI-запросы для Client.
Build/Runtime Makefile, build/, logs/ Сборка и артефакты запуска Собирает build/server и build/client, хранит временные артефакты сборки и runtime-логи logs/server.log/logs/client.log.

  • make DEBUGGAME=1 включает debug define, который используется интерфейсом.
  • UI поддерживает несколько терминальных профилей и показывает предупреждение, если терминал меньше минимального поддерживаемого размера.
  • Файлы карты лежат в Interface/Inc/Maps.
  • Сервер сейчас использует порт 5555, заданный напрямую в Server/Src/main.cpp.
